# QA Assistant Documents

This directory keeps QA Assistant second-development documents isolated from upstream OpenCode documentation.

## Directory Layout

```text
specs/qa-assistant/
  AGENTS.md
  README.md
  planning/
    qa-assistant-v0.1.md
  learning/
    opencode-learning-path.md
  operations/
    sync-upstream.md
```

## Categories

- `planning/`: MVP scope, implementation plans, milestones, acceptance criteria, and roadmap decisions.
- `learning/`: OpenCode source learning paths, module walkthroughs, architecture notes, and investigation notes.
- `operations/`: upstream sync records, release checklists, merge notes, and maintenance runbooks.
- `standards/`: future schema, field specifications, quality rubrics, and test case templates.
- `prompts/`: future QA Agent prompts, prompt rules, examples, and review checklists.
- `architecture/`: future detailed architecture, integration boundaries, sequence diagrams, and adapter designs.

Create a new subdirectory when a document has a durable category. Keep one-off notes in the closest existing category until they need their own home.
